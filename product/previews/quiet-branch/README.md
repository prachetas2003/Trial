# Quiet Branch — music preview

A standalone two-minute instrumental audition for Mischief: slow piano,
soft sustained ambience, no percussion or vocals, with gentle opening/closing
fades. 48 BPM; stereo AAC in an H.264 MP4 with a static title card.

The composition is original. No audio from the supplied WhatsApp reference is
included. The reference could be inspected as audio data but was not auditioned
by the assistant; this is a first draft, not a claim of an exact timbral match.

Piano instrument rendering uses FluidSynth and the TimGM6mb soundfont by Tim
Brechbill and David Bolton. The installed soundfont is licensed GPL-2; its
copyright/source information is maintained by the Debian timgm6mb-soundfont
package. Ambient pads and bass are synthesized separately. The soundfont itself
is not included here. score.json records the original note arrangement.

This commit contains preview media only. App integration and timer-control
changes are separate work.
