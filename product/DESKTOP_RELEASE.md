Buildlings is a transparent desktop pet with autonomous wandering,
occasional cursor chasing, shaded artwork, playful jumps, and sparkles
when you stroke it with your cursor. Clicks pass through the pet.

Download **Buildlings-Windows-x64.zip**, extract the entire archive, and
open **Buildlings.exe**. Use its notification-area icon for controls.
See the included README for shortcuts and details.

This is an unsigned Windows 10/11 preview. The workflow runs the motion
tests and native Windows interaction checks before publishing a release.
SHA256SUMS.txt contains the archive checksum.

Try the movement in your browser:
https://prachetas2003.github.io/Trial/roam/
