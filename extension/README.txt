MISCHIEF FOCUS SHIELD 0.7.0 — CHROME / EDGE

INSTALL ONCE
1. Keep this entire FocusShield folder on your computer (do not move it later).
2. Open chrome://extensions or edge://extensions in the browser address bar.
3. Turn Developer mode on. Click Load unpacked and choose this folder.
4. In Mischief, press Ctrl+Alt+F, open Focus Shield > Connect your browser.
5. Copy its pairing code. Open Mischief Focus Shield from the browser's
   Extensions menu, paste the code, and click Connect browser.
6. Return to Mischief: the panel should say Connected.

USE
Choose Blocker Only or Deep Focus, or enable Focus Shield individually.
Websites & features: add domains (reddit.com), YouTube Shorts and Instagram
Reels. Tabs & workspace: mark specific tabs Lock, or select Work tabs and
turn Only my work tabs on. Work tabs still obey website/feature rules.
Select currently open work tabs again after a browser restart. New tabs are
locked while Only my work tabs is active; approve needed tabs in the panel.
Start the focus timer. Pausing, finishing, breaks and quitting release blocks.
The extension menu has Pause timer & unlock for emergencies.

LIMITS AND YOUR DATA
Works in browser profiles where this extension is installed and paired.
Firefox, apps and other profiles are not blocked. Private windows require
allowing the extension in private/incognito mode; this is off by default.
Browser settings/internal pages, the Chrome Web Store and other pages where
Chrome disallows extensions cannot be covered. Tab buttons stay clickable;
locked website content is covered. It is a voluntary focus aid, not a lock
that prevents disabling extensions or changing browsers.
Existing pages remain underneath a cover, keeping their document/form values
when possible. A new blocked navigation uses a focus page and restores its
original URL on release. Closing/reloading tabs can still lose website state.
Shorts/Reels rules target their URLs and common links; site design changes
can require updates. Embedded feeds outside those paths may remain visible.

The extension needs website access to cover pages and hide selected links,
and tabs permission to let you choose work tabs. It sends current open tab
URLs/titles only to Mischief on 127.0.0.1:43827 with your pairing code. It does
not send page contents or browsing data to an external service. Mischief
keeps current tab inventory only in memory; selected tab IDs and configured
website domains are saved locally. Saving for later explicitly adds a URL to
Keep my thoughts. Do not share your pairing code.

If Mischief disconnects, restrictions release on the next sync. Sleeping or
closing the browser can delay sync; it clears old rules when the worker starts.
If something is stuck, disable this extension from the browser Extensions menu.
To update: keep the same folder path, replace files, then click Reload on its
extension card. Loading a different folder may need re-pairing and reselecting
tabs. Quit Mischief with Ctrl+Alt+Q or the tray's Quit Buildlings menu.
